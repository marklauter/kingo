The question Contains answers. A fact about one subject, held as a hypothesis rather than stored: does the closure contain it at this snapshot? The member is always a subject. A subject set in that seat would make the question set-valued, and a question is about one subject.

## Contrasts

- `fact` — a stored assertion with a lifecycle. A putative fact is the same shape held as a hypothesis. The difference is stance.
